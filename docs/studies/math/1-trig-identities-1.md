## Trig Identities

## 1. Reciprocal Identities
                                         
| KaTeX Code                                              | Rendered Formula                                       |
| :-------------------------------------------------------| :----------------------------------------------------- |
| \sin \theta &= \frac{1}{\csc \theta}                    | $\sin \theta &= \frac{1}{\csc \theta}$                 |
| \cos \theta &= \frac{1}{\sec \theta}                    | $\cos \theta &= \frac{1}{\sec \theta}$                 |
| \tan \theta &= \frac{1}{\cot \theta}                    | $\tan \theta &= \frac{1}{\cot \theta}$                 |
| \csc \theta &= \frac{1}{\sin \theta}                    | $\csc \theta &= \frac{1}{\sin \theta}$                 |
| \sec \theta &= \frac{1}{\cos \theta}                    | $\sec \theta &= \frac{1}{\cos \theta}$                 |
| \cot \theta &= \frac{1}{\tan \theta}                    | $\cot \theta &= \frac{1}{\tan \theta}$                 |

## **2. Quotient Identities**
                                           
| KaTeX Code                                              | Rendered Formula                                       |
| :-------------------------------------------------------| :----------------------------------------------------- |
| \tan \theta &= \frac{\sin \theta}{\cos \theta}          | $\tan \theta &= \frac{\sin \theta}{\cos \theta}$       |
| \cot \theta &= \frac{\cos \theta}{\sin \theta}          | $\cot \theta &= \frac{\cos \theta}{\sin \theta}$       |

## **3. Pythagorean Identities**
                                        
|KaTeX Code                                               | Rendered Formula                                       |
| :-------------------------------------------------------| :----------------------------------------------------- |
| \sin^2 \theta + \cos^2 \theta &= 1                      | $\sin^2 \theta + \cos^2 \theta &= 1$                   |
| 1 + \tan^2 \theta &= \sec^2 \theta                      | $1 + \tan^2 \theta &= \sec^2 \theta$                   |
| 1 + \cot^2 \theta &= \csc^2 \theta                      | $1 + \cot^2 \theta &= \csc^2 \theta$                   |

| \csc\left(\frac{\pi}{2} - \theta\right) &= \sec \theta  | $\csc\left(\frac{\pi}{2} - \theta\right) &= \sec \theta$ |

## **5. Even-Odd Identities**
                                           
| KaTeX Code                                              | Rendered Formula                                       |
| :-------------------------------------------------------| :----------------------------------------------------- |
| \sin(-\theta) &= -\sin \theta                           | $\sin(-\theta) &= -\sin \theta$                        |
| \cos(-\theta) &= \cos \theta                            | $\cos(-\theta) &= \cos \theta$                         |
| \tan(-\theta) &= -\tan \theta                           | $\tan(-\theta) &= -\tan \theta$                        |
| \csc(-\theta) &= -\csc \theta                           | $\csc(-\theta) &= -\csc \theta$                        |
| \sec(-\theta) &= \sec \theta                            | $\sec(-\theta) &= \sec \theta$                         |
| \cot(-\theta) &= -\cot \theta                           | $\cot(-\theta) &= -\cot \theta$                        |

## **6. Double Angle Identities**
                                       

| KaTeX Code                                              | Rendered Formula                                          |
| :-------------------------------------------------------| :-------------------------------------------------------- |
| \sin(2\theta) &= 2\sin \theta \cos \theta               | $\sin(2\theta) &= 2\sin \theta \cos \theta$               |
| \cos(2\theta) &= \cos^2 \theta - \sin^2 \theta          | $\cos(2\theta) &= \cos^2 \theta - \sin^2 \theta$          |
| &= 2\cos^2 \theta - 1                                   | $&= 2\cos^2 \theta - 1$                                   |
| &= 1 - 2\sin^2 \theta                                   | $&= 1 - 2\sin^2 \theta$                                   |
| \tan(2\theta) &= \frac{2\tan \theta}{1 - \tan^2 \theta} | $\tan(2\theta) &= \frac{2\tan \theta}{1 - \tan^2 \theta}$ |
