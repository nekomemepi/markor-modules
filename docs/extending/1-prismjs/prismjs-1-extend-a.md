# Boomer Logic

## Extending Markor with PrismJS

### conclusion

`Markor` is already a mature, feature rich, app for editing and
presenting markdown on Android. While our code works, it is far from
complete, and is just one boomer's attempt at extending Markor for our
use cases. Given that we dislike CSS and JavaScript more than we
loathe python, there will be better ways to achieve a more flexible
result.

Edge cases will always occur, and the wishlist for new features in
Markor will be long enough as it is. It will be much easier to adapt
our code when we have another crazy idea we might want to implement.
